# ISPAG Tank Builder 🏗️

Configurateur technique avancé pour la conception de réservoirs, chauffe-eau et accumulateurs d'énergie.

## Description
Ce plugin permet de définir précisément les caractéristiques techniques d'une cuve :
- Calcul des dimensions (Diamètre, Hauteur, Volume).
- Gestion des pressions de service et de test.
- Configuration dynamique des piquages (Fittings) via une interface visuelle.
- Gestion des types de soudures et plaques perforées (Welding).

## Installation
1. Télécharger le dossier dans `/wp-content/plugins/`.
2. Activer le plugin via le tableau de bord WordPress.
3. Configurer les paramètres dans l'onglet ISPAG.
